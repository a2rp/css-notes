# CSS Study Notes

These are my personal study notes from learning and working with CSS. I use this repository to keep the core concepts, layout patterns, browser behavior, and examples I want to revisit in one place.

The notes start with CSS syntax and the cascade, then build toward page layout, responsive design, interaction states, animation, accessibility, debugging, and maintainable styles. Each chapter explains what a feature does, when it is useful, and how it behaves in a real page.

## What I am covering

This is a focused reference for learning CSS from the fundamentals through the features used to build modern interfaces. It covers the box model, typography, Flexbox, Grid, positioning, responsive rules, custom properties, accessibility, performance, and CSS organization.

The examples use plain HTML and CSS so the browser behavior stays clear. Try each example in a small page, inspect it in browser developer tools, and change one value at a time to see how the layout responds. Browser support can vary, so check compatibility when using newer CSS features.

## Chapters

01. [Foundations and CSS syntax](./chapters/01-foundations-and-css-syntax.md)  
   Understand stylesheets, rules, declarations, comments, and how the browser applies CSS.

02. [Selectors, specificity, and the cascade](./chapters/02-selectors-specificity-and-cascade.md)  
   Choose elements reliably and reason about cascade order, specificity, inheritance, and source order.

03. [Values, units, and colors](./chapters/03-values-units-and-colors.md)  
   Use common CSS value types, lengths, percentages, color formats, and responsive sizing.

04. [The box model and layout flow](./chapters/04-box-model-and-layout-flow.md)  
   Work with content, padding, borders, margins, sizing, overflow, and normal document flow.

05. [Typography and text](./chapters/05-typography-and-text.md)  
   Set readable fonts, line spacing, text flow, wrapping, and font fallbacks.

06. [Backgrounds, borders, and shadows](./chapters/06-backgrounds-borders-and-shadows.md)  
   Layer backgrounds, crop images, style borders, and use shadows with restraint.

07. [Flexbox layout](./chapters/07-flexbox-layout.md)  
   Arrange items along a flexible axis and control alignment, wrapping, gaps, and growth.

08. [Grid layout](./chapters/08-grid-layout.md)  
   Build two-dimensional layouts with tracks, areas, auto placement, and responsive patterns.

09. [Positioning and stacking context](./chapters/09-positioning-and-stacking-context.md)  
   Place elements with static, relative, absolute, fixed, and sticky positioning, then understand stacking.

10. [Responsive design and media queries](./chapters/10-responsive-design-and-media-queries.md)  
   Adapt layouts to available space with fluid values, media queries, and container-aware choices.

11. [Pseudo-classes, pseudo-elements, and forms](./chapters/11-pseudo-classes-elements-and-forms.md)  
   Style interaction states, generated content, focus, and native form controls accessibly.

12. [Transforms, transitions, and animations](./chapters/12-transforms-transitions-and-animations.md)  
   Create motion and visual changes while respecting reduced-motion preferences.

13. [Custom properties and CSS functions](./chapters/13-custom-properties-and-css-functions.md)  
   Reuse values with custom properties and compose calculations, clamping, and modern color functions.

14. [Accessibility and inclusive CSS](./chapters/14-accessibility-and-inclusive-css.md)  
   Preserve focus visibility, contrast, readable content, semantic flow, and user motion preferences.

15. [Debugging, performance, and browser tools](./chapters/15-debugging-performance-and-browser-tools.md)  
   Inspect computed styles, trace layout issues, and reduce unnecessary rendering work.

16. [CSS architecture and modern CSS](./chapters/16-css-architecture-and-modern-css.md)  
   Organize styles by responsibility and use cascade layers, logical properties, and progressive enhancement.

## Using these notes

Read the chapters in order when learning CSS, or open the chapter for the property or layout problem you are working on. Build each example in a local HTML file, check it at more than one viewport width, and use the browser inspector to compare the rule you wrote with the computed style.
